FIXOTECH — Product images for quotation & Indent
================================================
Drop product photos here. Name them with these slugs (or edit MAP in
../../product-images.js). Extensions tried: .png .jpg .jpeg .webp

Cable trays:
  perforated-cable-tray   ladder-cable-tray   solid-cable-tray
  raceway                 cable-tray (generic fallback)

Fittings / accessories:
  perforated-reducer  ladder-reducer  reducer
  horizontal-bend  vertical-bend  bend
  tee  cross  coupler  end-plate  cover  support

Notes:
- One image can cover several variants; the generic slug is the fallback
  (e.g. any reducer without its own file uses reducer.*).
- If a product has no image, nothing is shown (no broken icon).
- More specific keyword wins (perforated reducer > reducer).
