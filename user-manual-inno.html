Getting started

  1. Log in with the shared ID and password.
  2. At the top, choose FIXOTECH Inno Structures — the Inno apps appear.
  3. Open Office Side. You'll see five apps: Quotation Calculator, Sales OQ, Invoice Gen, Inventory Management and Reports.

How the documents connect

Quotation→Sales Order→Invoice

Make a Quotation, convert it to a Sales Order once accepted, then convert that to a Tax Invoice. Each document keeps a link back to the one it came from, and you can click along the chain. You can also bypass straight from a Quotation to an Invoice, or start any document on its own.

Everything is interlinked and auto-saved. Customers and inventory items are shared by all five apps — change an item once and it updates everywhere. Drafts survive a refresh; only 🗑 Clear empties one.

1 · The shared toolbar

Quotation, Sales OQ and Invoice Gen work the same way. Across the top you'll find:

  • Session tabs + ＋ — keep several documents open at once (like the calculator's Order 1/2/3).
  • 💾 Save — save the current document to its records.
  • 📋 … records — the history: all saved quotations / sales orders / invoices, split into Drafts and Completed.
  • 🔢 Numbering — set the next document number (see section 7).
  • 📦 Inventory — the shared item master.
  • 🧮 Tally code — export for Tally (Invoice & Sales Order only).
  • 🗑 Clear — empty the current draft (records are safe).

Filling a document (common steps)

  1. Customer. Type the name — saved customers auto-suggest; click one to fill GSTIN, address and place-of-supply. New customer? Click ＋ New customer, fill the details and Save.
  2. Details. Check the number, date, PO, place of supply, GST % and discount. Place of supply decides CGST+SGST (within Karnataka) vs IGST (other states) automatically.
  3. Items. Click 🔎 Pick from inventory to add a saved item, or type a name (it auto-fills HSN, rate, SKU). Set Qty; the amount and totals update live. + Add row for more.
  4. Preview & print. Press 🖨 Verify & Print. In the preview you can click any cell to edit — totals recalculate live — then 💾 Save changes and Print / Save PDF. Every PDF carries the logo and authorised stamp.
  5. Move it forward with the status buttons and the convert button at the bottom.

2 · Quotation Calculator Step 1

Create a price quotation (number like FIS26/27-QT001).

  1. Fill customer, details and items (section 1).
  2. Use the status buttons: Save as Draft, Save & Send, ✓ Accepted or ✕ Declined.
  3. Once accepted, press ➡ Convert to Sales Order — a Sales Order is created and linked. Need to skip a step? Use ⏩ Bypass → Invoice.

3 · Sales OQ — Sales Order Step 2

The confirmed order (number like FIS26/27-SO001), usually created from a quotation.

  1. Check the details carried over from the quotation (shown as a link at the top).
  2. Press ✓ Confirm order when the customer confirms.
  3. Press ➡ Convert to Invoice to raise the tax invoice.
  4. See all past orders any time with 📋 Sales Order records (your order history), filtered by Drafts / Completed.

4 · Invoice Gen — Tax Invoice Step 3

The GST tax invoice (number like FIS26/27-001).

  1. Create from a Sales Order (or on its own), check items and GST.
  2. Use 🖨 Verify & Print for the final invoice / approval copy.
  3. Status: Save as Draft, Save & Send, ✓ Client approved, ✕ Not approved.
  4. When an invoice is approved, the sold quantities are automatically removed from inventory stock.
  5. Export to Tally with 🧮 Tally code (section 8).

5 · Inventory Management Shared

One item master used by every Inno app. Open the standalone Inventory Management app, or the 📦 Inventory button inside any document — it's the same data.

  1. See the summary: total Items, Low stock count and Stock value.
  2. Filter by All / Low stock / Products / Raw materials / Services, or search by name, SKU, HSN or category.
  3. ＋ New item to add one: name, custom SKU, HSN, unit, rate, category, stock on hand and reorder point.
  4. Edit any item — changes show instantly in every app. 📄 shows every quotation / sales order / invoice that used that item.
  5. Items at or below their reorder point are flagged ⚠ Low.
  6. Use Export / Import to back up or load items.
Selling an item on an approved invoice reduces its stock automatically, so Stock on hand stays accurate.

6 · Reports

Your whole business at a glance.

  • Operations snapshot — today's invoiced value, quotes and orders; what's pending; and Won / Lost / In-progress.
  • Deal / project board — every sale across Quotation → Sales Order → Invoice with its current stage.
  • KPI tiles — invoiced value, taxable value, GST, quotations, sales orders and quote→invoice conversion.
  • Period views — switch between Weekly, Monthly, Quarterly and Yearly with a chart and breakdown table.
  • Financial Year selector (top) to look at a past year.
  • 🖨 PDF report and 📊 Presentation — both include monthly and quarterly figures and the deal board.

7 · Document numbering

Numbers follow the financial year and roll over every April: Quotation FIS26/27-QT001, Sales Order FIS26/27-SO001, Invoice FIS26/27-001.

  1. You're rarely starting at 001, so press 🔢 Numbering and set the next number for each type (e.g. next Invoice = 142).
  2. New documents continue from there. You can still type any number directly on a document — the counter jumps past it so numbers never repeat.

8 · Tally export

No live connection needed — you copy a code and paste it into Tally.

  1. Press 🧮 Tally code on an invoice (or in records, use Export all to Tally / Tally — this view).
  2. Click Copy (or Download .xml).
  3. In Tally: Gateway of Tally → Import Data → Vouchers, paste/import the file.
The code uses the customer and the ledgers Sales and Output CGST / SGST / IGST. Create those ledgers once in Tally and every import maps cleanly.

9 · Admin — Inno Data

In the Admin panel, the 🏗️ Inno Data tab shows live counts of customers, inventory, quotations, sales orders and invoices, with a record viewer. From here the administrator can Export a full backup or Import data (for example historical records).

10 · FAQ & troubleshooting

Q. I refreshed and lost my invoice.
It's kept — check the session tabs at the top. Only 🗑 Clear empties a draft, and saved documents are always in 📋 records.

Q. My numbers don't start at 001.
Use 🔢 Numbering to set the next number for each type. Or just type the correct number on the document — the counter follows it.

Q. The report figures look small / only yearly.
Use the Weekly / Monthly / Quarterly / Yearly buttons on the "Invoiced value" card, and the Financial Year selector at the top.

Q. Can I edit an invoice's numbers in the PDF?
Yes — in Verify & Print, click any cell; totals recalculate live. Press 💾 Save changes to keep them.

Q. Where do I see all orders for one product?
Inventory → open the item's 📄 to see every quotation, sales order and invoice that used it.

Q. Stock isn't reducing.
Stock drops when an invoice is approved (the sale is final), and only once per invoice. Imported historical invoices don't change current stock.
